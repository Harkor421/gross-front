## 📖 Sobre el proyecto

Sitio de una sola página para el dispensador **Gross income**. Renderiza un estado de resultados en vivo, la cuenta regresiva de la próxima entrega, un diagrama animado del split 50/50 y el feed de pagos.

## ✨ Qué hace

- Estado de resultados en vivo (las fees como ingreso bruto)
- Diagrama animado del split 50/50
- Countdown de la próxima entrega y feed de pagos
- React 19 + Vite 7, sin dependencias de UI

## 🚀 Empezar

```bash
git clone https://github.com/Harkor421/gross-front.git
cd gross-front
npm install
npm run dev
```

## 📜 Scripts

| Comando | Qué hace |
|---|---|
| `npm run dev` | Servidor de desarrollo con recarga en caliente |
| `npm run build` | Compila para producción |
| `npm run start` | Arranca la aplicación |
